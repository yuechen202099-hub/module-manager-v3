## Root Cause

- 长条码未匹配记录完成临时审阅后，正式关联依赖唯一候选、版本及照片证据的严格一致性。
- 四个照片分类条目的包装地址路径相同，但 `downloadImg` 查询参数分别指向四张不同物理图片。
- V3.0.81 的照片来源归一化错误删除了完整查询串，导致四张不同照片拥有相同来源 hash；仓储层因此只写入一条 `Photo`，而关联后的旧校验也误判为证据完整。
- V3.0.82 改为只移除临时签名参数并保留 `downloadImg` 等稳定图片身份，同时补充兼容旧 hash 的去重和事务化补图。
