# Project Workflow Module Toggles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let each project enable only the workflow modules it actually needs while keeping required workflow nodes protected.

**Architecture:** The workflow editor remains the single frontend surface for project process configuration. Module rows are derived from workflow node `moduleId` values and project module names; toggling a module updates the matching nodes, normalizes enabled-node order, and rebuilds preview edges before the existing save flow persists the workflow.

**Tech Stack:** Vue 3, TypeScript, Element Plus, existing project workflow API, focused Node guard scripts, local platform dev server.

---

## Context

- Production baseline: `production/V3/3.0.71`.
