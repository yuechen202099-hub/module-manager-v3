# V3.2.19 表计按表号去重发布计划

## 目标

将同一终端内施工前、施工后的同一表计按表号合并，作为 V3.2.19 可回滚发布上线。

## 范围

- 表计按规范化表号去重；表号为空时仍按资料组隔离，避免误合并。
- 已施工资料优先，未施工资料仅补齐采集器号、模块号等空字段，不覆盖已施工值。
- 同表号的未施工历史异常不阻塞已施工资料翻拍。
- 采集器需求继续按采集器编号去重，不把模块号和采集器号混为同一字段。
- 不新增数据库迁移，不修改生产业务数据，不触发 OSS、相机或甲方平台写入。
