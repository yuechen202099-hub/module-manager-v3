# V3.2.0 数据中台审阅与统一导出中心设计

## 1. 目标

V3.1.1 已实现资料组条码核验、满足条件后的自动归档，以及审阅完成后的后台交付缓存。V3.2.0 取消重复的终端式人工审阅工作流，把人工复核统一收口到管理员数据中台，并建立全站唯一的管理员导出中心。

本版本必须同时完成：

- 删除审阅员角色和独立审阅工作台。
- 数据中台按资料组平铺，逐条弹窗审阅，不按终端分组。
- 驾驶舱可视化点击后携带筛选条件跳转数据中台。
- 全站现有业务导出统一迁移到导出中心。
- 新增终端号、表号、模块号、采集器号四类去重设备清单。
- 展示终端最终交付包是否可导出及明确阻断原因。
- 所有明细列表默认每页 20 条，并允许选择 20、50、100。

版本号为 `V3.2.0`。

## 2. 产品边界

### 2.1 保留的角色

系统只保留：

- `admin`：项目管理、资料复核、数据编辑、派发、导出和账号管理。
- `constructor`：施工采集及被指派的现场异常处理。

`reviewer` 不再是有效角色。现有仅含 `reviewer` 的账号立即停用，但保留账号原始信息和历史审计，不自动提升为管理员。既有 token 在下一次受保护请求时失效并跳转登录页。管理员可以删除停用账号或将其明确改为施工员。

历史资料组中的审阅人、审阅时间、审阅事件和审计记录永久保留。字段名可以继续使用 `reviewer` 表达历史业务语义，不因为角色删除而重命名或清空。

### 2.2 退出的页面与流程

- 删除主导航“审阅工作台”。
- 删除终端领取、释放和按终端逐组完成审阅的流程。
- “任务领取”改为“任务派发”，仅保留施工指派、改派、优先施工和施工状态。
- `/task-hall` 重定向到 `/global-search`。
- `/review/:groupId` 重定向到 `/global-search?group_id=:groupId&review=1` 并自动打开对应资料组弹窗。
- 原审阅写接口保留满足数据中台需要的能力，但权限收紧为管理员；废弃的领取接口不再从前端调用。

## 3. 数据中台

### 3.1 页面定位

数据中台是管理员唯一的资料明细和人工复核入口。主列表不按终端分组，每一行表示一个正式资料组或一条未匹配证据。

默认每页 20 条，分页大小可选 20、50、100。分页、排序、筛选全部由服务器执行。筛选条件、页码、分页大小和当前资料组写入 URL 查询参数，支持刷新、浏览器前进后退和驾驶舱下钻。

### 3.2 列表字段

正式资料组横向展示：

- 终端号
- 表号
- 模块号
- 采集器号
- 安装人员姓名
- 照片数量
- 图片分类进度
- 扫码进度
- 施工状态
- 归档状态
- 异常状态
- 最后更新时间

扫码进度必须使用同一资料组级口径：

- `3/3`：表号、模块号、采集器号均已核验。
- `2/3`、`1/3`、`0/3`：显示缺少的设备项。
- `人工通过`：管理员已确认现有证据与填报值一致。
- `异常不匹配`：识别值与填报值冲突。
- `无法识别`：条码、二维码和受控 OCR 均无可靠结果。

### 3.3 筛选

数据中台支持组合筛选：

- 数据类型：全部、正式资料组、未匹配证据。
- 施工状态：未施工、施工中、已施工。
- 归档状态：未归档、待归档、已归档。
- 扫码状态：通过、待人工、异常不匹配、无法识别、不符合条件。
- 图片分类：完整、不完整。
- 异常状态：缺照、缺设备号、重复模块、现场异常。
- 安装人员。
- 施工日期范围。
- 终端号。
- 关键词：表号、模块号、采集器号、终端号和地址。

所有筛选使用服务端查询。前端切换筛选时取消或淘汰旧请求，旧响应不能覆盖新状态。

### 3.4 统一审阅弹窗

点击任意行按资料组 ID 或未匹配证据 ID 懒加载完整明细和照片。弹窗由三个区域组成：

1. 资料字段：终端号、表号、模块号、采集器号、安装人员、地址、状态和异常说明。
2. 照片证据：四张照片切换、局部放大、框选扫码、条码、二维码和 OCR 候选。
3. 核验操作：重新扫码、人工确认、保存分类、修正字段、转异常工单、回退状态和查看审计。

弹窗行为：

- 不再提供普通“完成审阅”按钮。
- 条码和 OCR 只生成候选，不直接修改正式字段。
- 框选结果必须由管理员确认后才能写入指定的表号、模块号或采集器号字段。
- 人工确认必须二次确认并填写原因。
- 修改照片、分类、表号、模块号、采集器号、终端或地址后，使旧扫码结论、归档状态和交付缓存失效。
- 图片分类完整、资料组级扫码通过且正式身份有效时，系统自动归档并后台生成交付缓存。
- 异常或缺照资料可生成施工异常工单。
- 未匹配证据只能关联唯一确定的现有资料组或终端；禁止创建 `00000000` 或其他占位工单。
- 已归档资料默认只读，管理员可以二次确认后回退至未审阅或未施工。
- 回退至未施工时继续清空照片、模块号、采集器号和扫码通过标记。
- 所有写操作记录管理员、时间、原因、修改前后值和来源页面。

### 3.5 性能

- 列表仅返回轻量字段，不包含照片二进制或完整识别明细。
- 照片仅在打开弹窗后加载，优先使用平台交付缓存。
- 服务端为组合筛选提供稳定排序和必要索引。
- 数据中台不加载全量资料组后在浏览器筛选。
- 关闭弹窗释放图片对象 URL 和未完成请求。

## 4. 驾驶舱下钻

驾驶舱只承担汇总、趋势和风险发现，不再维护重复明细弹窗。以下可视化全部改为可点击，并跳转到带筛选条件的数据中台：

| 驾驶舱可视化 | 数据中台目标筛选 |
| --- | --- |
| 资料组 | 正式资料组、全部状态 |
| 已扫码组 | 正式资料组、已有施工扫码数据 |
| 已归档 | 归档状态为已归档 |
| 条码准确率 | 符合扫码条件的全部资料组 |
| 核验通过 | 扫码状态为通过 |
| 待人工 | 扫码状态为异常不匹配或无法识别 |
| 不符合条件 | 扫码状态为不符合条件 |
| 已扫码进度 | 已有施工扫码数据 |
| 已归档进度 | 已归档 |
| 扫码未匹配 | 数据类型为未匹配证据 |
| 异常与缺照 | 异常状态为缺照或其他异常 |
| 未施工未扫码 | 未施工且无扫码数据 |
| 终端总数 | 对应终端范围下的全部资料组 |
| 已完成施工 | 对应终端状态下的已施工资料组 |
| 未完成施工 | 对应终端状态下的未完成资料组 |
| 待归档 | 已施工且未归档 |
| 安装人员完成量 | 对应安装人员和驾驶舱当前日期范围 |

数据中台仍按资料组平铺。终端号和终端状态只是筛选条件，不重新产生终端分组审阅页面。

浏览器返回驾驶舱时保留原日期范围和人员范围。驾驶舱继续读取服务器定时快照，点击下钻不触发驾驶舱全量重算。

## 5. 导出中心

### 5.1 页面定位

新增管理员专用“导出中心”，作为全站唯一业务数据导出入口。原项目驾驶舱、任务派发和其他页面删除业务导出按钮。

导入模板下载仍保留在对应导入弹窗旁，因为模板属于导入操作，不属于业务数据导出。

导出中心包含四个标签页：

1. 终端交付
2. 设备清单
3. 业务清单
4. 统计报表

列表默认每页 20 条，可选 20、50、100。

### 5.2 终端交付

按终端展示：

- 终端号
- 资料组总数
- 已施工数量
- 已归档数量
- 交付缓存就绪数量
- 状态：可导出、缓存生成中、不可导出
- 阻断原因
- 最近生成时间
- 下载操作

“可导出”使用正式交付包现有校验规则的服务端预检结果。页面不得逐终端循环调用导出接口来试错。

最终交付 ZIP 继续由后台任务生成并复用缓存。请求未就绪时显示后台状态，不在 HTTP 下载请求中同步回源 OSS 或压缩照片。

### 5.3 设备清单

提供四种独立 Excel：

- 去重终端号
- 去重表号
- 去重模块号
- 去重采集器号

统一规则：

- 由服务器从当前项目正式业务数据生成。
- 排除空值、`00000000` 和其他占位值。
- 去除首尾空白并执行确定性的文本规范化。
- 不做数值转换，保留前导零。
- 每个文件只有一列设备编号，并包含生成时间、项目和筛选范围元数据。
- 去重结果使用稳定排序。

### 5.4 业务清单

迁移并保留现有能力：

- 任务明细
- 异常表计
- 异常与缺照
- 换表清单
- 未匹配清单
- 条码复核清单
- 项目外施工

### 5.5 统计报表

迁移并保留：

- 安装人员 KPI
- 安装人员每日完成量

KPI 原公式和字段不因入口迁移而改变。

### 5.6 统一导出任务

所有业务导出由服务器生成，保存生成时的数据快照和筛选条件。大文件进入后台导出队列。

导出记录展示：

- 导出类型
- 筛选范围
- 行数或资料组数
- 创建人
- 创建时间
- 状态：等待、生成中、可下载、失败、已过期
- 失败原因
- 下载入口

每页默认 20 条，可选 20、50、100。导出创建和下载均写审计日志。过期文件按现有缓存保留和服务器最近版本清理纪律管理，不删除仍在下载或被有效任务租用的文件。

## 6. 权限与安全

- 数据中台复核、导出中心和所有导出接口仅管理员可用。
- 施工员不能通过旧 URL、旧 token 或直接请求调用审阅和导出接口。
- `reviewer` token 不再满足任何受保护业务接口。
- 导出筛选字段使用明确白名单，文件名由服务端生成。
- 导出设备编号使用 Excel 文本单元格，避免前导零丢失和公式注入。
- 所有照片读取继续使用受控本地路径、OSS 签名地址或既有代理校验，不接受客户端任意 URL。

## 7. 迁移与兼容

- 数据库迁移或账户存储迁移将 reviewer-only 账号标记停用。
- 清理现存审阅任务领取状态并写系统审计，历史审阅事件不变。
- 旧导航、书签和历史链接使用重定向，不返回空白页。
- 原导出 API 在一个生产版本内保留兼容，但统一改为管理员权限；前端只使用导出中心的新入口。
- 发布前备份 `.env`、data、uploads、交付缓存和 PostgreSQL。

## 8. 验收

1. 主导航无审阅工作台，账号管理不能创建 reviewer。
2. reviewer-only 存量账号不能继续访问业务接口，历史审计仍可查询。
3. 数据中台按资料组平铺，默认 20 条，可切换 20、50、100。
4. 所有组合筛选、页码和分页大小使用服务端查询并同步 URL。
5. 点击资料组打开统一审阅弹窗，照片按需加载。
6. 分类完整且资料组扫码通过后自动归档并排队生成交付缓存。
7. 人工确认、字段修改、异常派发和回退均写完整审计。
8. 未匹配证据不能生成 `00000000` 占位工单。
9. 驾驶舱列出的每个可视化均可跳到匹配筛选的数据中台。
10. 驾驶舱不再保留被迁移的重复明细弹窗和导出按钮。
11. 导出中心包含终端交付、设备清单、业务清单和统计报表。
12. 四类设备 Excel 去空、去重、排除占位值并保留前导零。
13. 终端交付列表准确显示可导出、生成中和不可导出及阻断原因。
14. 所有原有业务导出只能从导出中心发起，结果与迁移前口径一致。
15. 导出记录默认 20 条，可切换 20、50、100，失败可见原因。
16. 后台导出和交付包生成不阻塞页面，不在下载请求中回源 OSS。
17. 管理员和施工员的既有施工、异常处理、KPI 和自动归档行为无回归。

## 9. 发布

V3.2.0 属于流程级大更新。发布顺序为：

1. 测试先行完成角色、分页、审阅、下钻和导出契约。
2. 完成后端迁移与兼容接口。
3. 完成数据中台、驾驶舱和导出中心前端。
4. 执行完整后端测试、前端类型检查、生产构建、发布门禁和独立代码复审。
5. 备份生产环境并生成可回滚发布包。
6. 低风险迁移存量 reviewer 账号和审阅领取状态。
7. 切换版本并检查页面、API、后台 worker、交付缓存和导出任务。
