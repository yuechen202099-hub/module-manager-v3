## Summary

This package makes the device replacement hierarchy rule easier to apply from the graphical field designer.

- The field graph now shows two operator-facing replacement hierarchy templates:
  - module replacement: task object -> accessory device replacement
  - terminal replacement: task object -> main device replacement -> accessory replacement confirmation
- Clicking a template emits an apply event instead of leaving the rule as passive guidance.
- The projects page handles the event for both new projects and draft schema editing.
- Applying a template replaces known replacement-template fields with the selected hierarchy while preserving extra project-specific custom fields.
