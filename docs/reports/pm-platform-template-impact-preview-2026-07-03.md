## Summary

This package makes draft field configuration show how the current field hierarchy affects import templates before the backend preview endpoint is available.

- The graphical field designer now builds local preview rows from the current schema.
- Initial import template preview shows only task object, aggregate field, and import fields.
- System-external completed template preview shows import, field-collection, and photo evidence fields that operators may provide when taking over a half-finished project.
- Platform-required KPI/audit fields are listed separately as upload-time generated fields.
- Local preview rows preserve parent field labels and conditional collection hints, so module and terminal replacement hierarchy remains visible in the template area.
