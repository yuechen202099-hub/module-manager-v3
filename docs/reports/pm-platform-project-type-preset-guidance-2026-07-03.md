## Scope

The create-project dialog now shows a business guidance card when the user selects a project type preset.

The card explains:

- Current preset name.
- Main field.
- Aggregate field.
- Replacement hierarchy mode.
- For terminal replacement: aggregate can be `台区、地区或厂家`, but the project must `同时仅保留一种聚合字段`.
